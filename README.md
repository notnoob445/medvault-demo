# MedVault: Encrypted Clinical Records with Cost and Compliance Governance
BCSE355L Cloud Architecture Design · Team 30 · A2 slot · 24BDS0064

- `MedVault.ipynb`: Colab notebook, already run with its outputs saved. It writes and runs the evaluation harness, draws every figure from the CSVs, prints the result tables, models the USD 20 budget and 80% alert, and demonstrates envelope encryption with the key-policy deny.
  Open in Colab: https://colab.research.google.com/github/notnoob445/medvault-demo/blob/main/MedVault.ipynb
- `medvault_eval.py`: the evaluation harness. It is a local simulation of Existing-A, Existing-B and the proposed MedVault design over the synthetic SCW-64 workload (seed 24064).
- `make_figs.py`: draws the graphs in `figs/` from `results/*.csv`.
- `input_results/`: the original CSVs used in the paper. `results/` and `figs/` hold the outputs regenerated by the notebook run. Latency values vary slightly from run to run.
- `index.html`: the static MedVault console demo. Live at https://rawcdn.githack.com/notnoob445/medvault-demo/d8ef194871d39ddb6a1b0383756dd3a515059b01/index.html

Note: this is a local simulation, not a live AWS deployment. All patient data is synthetic.
